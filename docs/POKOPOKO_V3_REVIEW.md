# ポコポコアイランド v3「そよかぜと なかまたち」試作

基点: `0432ff694905ad7814180eb35b48c53a01e263b1`。
「Switch 2のゲームのような豊かさ」を目標にした最初の実装。コンソール同等の品質・性能を達成したという評価ではない。ブラウザ描画・iOS実機での確認が未完了のため、レビュー用として扱う。

## 変更

- 実際の島を周回する3Dタイトル。ゲーム中の世界をそのまま見せる。
- Standard material、色空間変換、ACESトーンマッピング、柔らかい影。
- シェーダーによる波、水面のきらめき、深さに応じた海の色。
- インスタンス描画の草と風、上限16匹の蝶、丸い雲。
- 丸い動物モデル、足と頭の動き、プレイヤーの呼吸。
- 届く場所と配置可否を示す設置ガイド。設置時の粒子。
- 直近40回までの編集を戻す操作。プレイヤーをブロック内に閉じ込める復元は拒否。
- UI配置と配色の改修。横スクロールのブロック棚は44px以上のタップ領域を確保。
- ポーズ画面の「うつり：かるい」は影を無効化し描画解像度を抑える。設定は実行中のみ。
- 昼夜サイクルを150秒から420秒へ変更。

## セーブ

v3は `pokopoko_island_v3_progress` に保存する。未保存の場合はv2、次にv1から移行。v1/v2には書き込まない。地形生成の乱数は装飾に使用せず、v2の地形・建築を維持する。v1由来の地形プロファイルも維持する。v3で作った建築はv2へ逆移行しない。

Undoはセッション内のみ。統計は累計操作数なのでUndoでスコア・ミッションを取り消さない。旧HTMLは残し、ラッパーのiframe参照だけをv3に変更。

## 検証

- `npm run build`: クライアント、SSR、全ルートのprerenderが成功。
- HTML内JavaScriptの `node --check`: 成功。
- `node scripts/test-pokopoko-v3.cjs /path/to/three-r128.min.js`: 成功。
  - v2移行後の全地形セル・建築データの一致。
  - キャラクター、統計、ミッション、動物待機、飛行、選択ブロックの一致。
  - 旧v2保存データがバイト単位で不変。
  - v3保存と再読込、v1からの直接移行。
  - Undoによる復元、プレイヤーとの重なり拒否。
  - 600フレームのロジック実行で座標が有限値。
  - 5回の再起動で装飾数が増殖しない。

テストにはゲームと同じ公式Three.js r128 UMDを渡す。DOMとWebGLRendererはスタブであり、シェーダーコンパイルや描画性能を検証するものではない。

## マージ前に残る確認

確認用ブラウザがプレビューへの接続を `ERR_BLOCKED_BY_CLIENT` で拒否したため、以下は未確認。

- WebGLシェーダーコンパイル、実際の色・影・カメラ、画面全体の見栄え。
- PC/スマホの表示崩れ・タッチ操作・設置ガイド。
- iOS/Android実機の起動・音・セーフエリア・発熱・フレームレート。
- 5分以上プレイしてのGPUメモリ・描画速度。
- ミッション完了から自由建築への一周。
- v3のプレイ画面を撮影して `public/thumbs/pokopoko-island.webp` を差し替える（現時点はv2の既存画像）。画像生成による代用はしない。

これらを満たすまではDraftのままにする。本番へのマージ・公開は今回実施しない。
